# User guide

Use Mission Control for the daily overview and Today for exact actions. Habits holds reusable routines and their scheduled check-ins. Planner generates editable schedule blocks only after preview. Focus Mode records a timed session and can complete its linked action. Academic pages track GATE, the 44-week AI roadmap, and Semester 5. Settings exports or restores a validated JSON backup.

Export before clearing browser data or replacing a backup. Imports replace current data only after confirmation.
