# Testing

Run `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, and `npm run rust:check`. Domain tests cover schedules, vacation/college boundaries, 44-week roadmap shape, streak preservation, non-scheduled and skipped days, completion rate, XP idempotency, levels, workload, and perfect-day rules. Playwright is reserved for browser smoke flows and requires installed browser binaries.
